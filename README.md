# Mafera FC Website

Official website for Mafera FC, a youth football club. It presents the club's teams, staff, fixtures, results and news in one place, and lets the club update content without touching code.

**Live preview:** https://simbarasheryan.github.io/mafera-fc-website/



![Mafera FC homepage](home.png)



## Features

- Pages for the club's age-group teams: U7, U11, U13, U15 and U17
- Staff section with names and roles
- Fixtures, results and news that the club can update, with text and pictures
- Password-protected access for content updates
- Responsive layout for phones and desktops

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML, CSS, JavaScript |
| Backend and database | Supabase |
| Hosting | GitHub Pages (preview) |

## Run Locally

```
git clone https://github.com/SimbarasheRyan/mafera-fc-website.git
cd mafera-fc-website
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
